## Overview
Core Java fundamentals form the foundation of every Java interview. This section covers the building blocks of the language, from data types and operators to modern features like records and sealed classes.

## Prerequisites
- Basic programming knowledge
- Understanding of compilation and execution concepts

## Key Takeaways
- Java is platform-independent through the JVM's "write once, run anywhere" philosophy
- Understanding primitive types vs wrapper classes is fundamental for performance
- Strings are immutable and pooled for memory efficiency
- Java is always pass-by-value (references are passed by value)
- Modern Java features (records, sealed classes) reduce boilerplate significantly

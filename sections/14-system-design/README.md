## Key Takeaways
- System design questions test your ability to apply concurrency, collections, and patterns
- Start with requirements/API, then data structures, then concurrency, then optimization
- Thread safety is a key consideration in all designs
- Consider scalability, fault tolerance, and monitoring from the start

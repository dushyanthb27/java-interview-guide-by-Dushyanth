### 3. **concurrency-terminology.md** - Concurrency (100+ entries)
**File Size**: 41 KB | **Entries**: 100+

Threading, synchronization, and concurrent programming concepts essential for multi-threaded applications.

#### Key Topics:
- **A-C**: Atomic operations, atomic variables, barriers, CAS (Compare-And-Swap), concurrent collections, ConcurrentHashMap, condition variables, CopyOnWriteArrayList, CyclicBarrier
- **D-F**: Deadlock, default methods, delegation, deserialization, futures
- **H-L**: Happens-before relationships, immutable objects, locks, lock-free programming
- **M-R**: Memory barriers, memory visibility, mutexes, race conditions, ReentrantLock
- **S-W**: Semaphores, synchronization, threads, thread pools, volatile, wait/notify

#### Interview Focus:
- Thread safety and synchronization
- Concurrent collections
- Deadlock prevention
- Memory visibility
- Lock-free programming
- Executor framework

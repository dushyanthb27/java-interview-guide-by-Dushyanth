# Java Interview Glossary

A comprehensive reference guide for Java terminology, concepts, and advanced topics designed for senior-level interview preparation.

## Overview

This glossary contains 600+ carefully curated Java terms and concepts organized across six specialized documents. Each entry includes definitions, practical examples, and interview tips to help you master Java terminology at the level expected for senior engineering positions.

## Glossary Files

### 1. **java-terminology.md** (300+ entries)
Core Java language features, fundamental concepts, and standard library terms. Covers everything from basic syntax to advanced language features.

**Topics Include**:
- Basic data types and operators
- Object-oriented programming concepts
- Collections and generics
- Exception handling
- Reflection and annotations
- Streams and functional programming
- Module system and packages

### 2. **concurrency-terminology.md** (100+ entries)
Threading, synchronization, and concurrent programming concepts. Essential for understanding multi-threaded applications and modern concurrency patterns.

**Topics Include**:
- Thread management and lifecycle
- Synchronization mechanisms
- Concurrent collections
- Executors and thread pools
- Locks and atomic operations
- Volatile and memory visibility
- Happens-before relationships

### 3. **jvm-terminology.md** (80+ entries)
JVM internals, memory management, and runtime concepts. Critical for understanding performance, debugging, and optimization.

**Topics Include**:
- Memory areas (heap, stack, metaspace)
- Garbage collection algorithms
- Class loading and bytecode
- JIT compilation
- Performance monitoring
- Profiling and debugging tools

### 4. **design-patterns-terminology.md** (50+ entries)
Gang of Four and modern design patterns with Java implementations. Important for architectural discussions and system design interviews.

**Topics Include**:
- Creational patterns
- Structural patterns
- Behavioral patterns
- Architectural patterns
- Concurrency patterns
- Enterprise patterns

### 5. **performance-terminology.md** (70+ entries)
Performance optimization, benchmarking, and tuning concepts. Essential for discussing scalability and optimization strategies.

**Topics Include**:
- Benchmarking and profiling
- Optimization techniques
- Memory optimization
- CPU optimization
- Caching strategies
- Latency and throughput concepts
